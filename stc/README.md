# Soham Tech Care (STC) — Portfolio Website

A modern, responsive, and high-tech portfolio website for **Soham Tech Care (STC)** led by **Soham Mondal** ("Fixing Today, Securing Tomorrow").

Built with **React**, **Vite**, **Tailwind CSS**, and **Lucide React**.

## 🚀 Running Locally

### Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Production Build
```bash
npm run build
```
Generates production-ready optimized HTML, CSS, and JS in the `dist/` directory.

### Preview Build
```bash
npm run preview
```
